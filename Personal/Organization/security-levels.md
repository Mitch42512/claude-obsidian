# Account Security Levels

> This file tracks **what security level each account uses** — not passwords.
> Actual passwords live in your password manager only.

## Security Tiers

| Level | Description | Examples |
|-------|-------------|---------|
| Level 1 | Highest — unique strong password + MFA | Finance, banking, crypto |
| Level 2 | High — unique strong password | Important accounts, work |
| Level 3 | Standard — unique password | Shopping, newsletters |
