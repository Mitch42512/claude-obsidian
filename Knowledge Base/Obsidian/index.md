# Obsidian

## What It Is
Obsidian is a local markdown note-taking app. All notes are plain `.md` files stored on your computer. It runs entirely offline by default.

## Key Concepts
- **Vault** — the folder Obsidian treats as your workspace (this folder)
- **Wikilinks** — `[[Note Name]]` links between notes
- **Frontmatter** — YAML at the top of a file (`---`) for metadata
- **Community plugins** — extend functionality (Claudian, Local REST API, etc.)
- **Canvas** — visual board for connecting notes as cards

## Plugins I Have Installed
| Plugin | What It Does |
|--------|--------------|
| Claudian | Claude Code as a sidebar chat inside Obsidian |
| Local REST API | Exposes vault to external tools via HTTP |

| Calendar | Calendar view in sidebar |
