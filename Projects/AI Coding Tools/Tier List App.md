# Tier List App 📊

## Concept

A social tier list app — create tier lists on any topic, publish them, and let the community rate and compare theirs.

## How It Works

1. User picks or creates a tier list template (e.g. "Sydney Suburbs", "90s Movies", "Pasta Shapes")
2. Drag items into tiers (S, A, B, C, D)
3. Submit your list publicly
4. Browse other people's lists on the same topic
5. Community rates / reacts to lists

## Features to Consider

- Curated template library
- Custom list creation
- Side-by-side comparison of two people's lists
- "Most agreed upon" aggregate tier list per topic
- Share to social media
