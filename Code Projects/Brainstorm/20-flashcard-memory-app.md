# 20. Flashcard Memory App

## Overview
An app for actively remembering anything. Add items you want to retain — facts, vocab, concepts — and the app cycles through them each time you open it. Cards stay in rotation until you remove them. One new card surfaces per session.

## Goals
- Add any piece of information you want to remember
- App cycles through cards on every open
- Remove a card once you've fully retained it
- One new card introduced per session so you're never overwhelmed

## Features
- Simple card creation — text front and back
- Random or spaced cycling through active cards
- Remove card when mastered
- One new card per session drip-feed mechanic
- Categories or tags for organising cards (optional)
